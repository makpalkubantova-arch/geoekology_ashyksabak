# Геоэкологиядағы антропогендік факторлар — ашық сабақ (10 «Б»)

Мұғалімі: Еспенбетова Айжан Сатыбалдиевна · Дінмұхамед Қонаев атындағы №9 ІТ мектеп-лицейі, Жетісай ауданы, Түркістан облысы.

## Беттер
- `index.html` — тақта: 9 экран, 45 минут. Әр экранда: ӘДІС → ҚАЛАЙ ОРЫНДАЙМЫЗ → ТАПСЫРМА.
- `quiz.html` — оқушы телефоны: топ пен рөл, «Экожарыс» квизі, кері байланыс. `&guest=1` — қонақ мұғалімдердің пікірі.
- `hatshy.html` — хатшы (жеңіл режим: «Бүкіл топқа» + түзету).
- `tour.html` — «Глобус-саяхат» бейнесінің беті (`?play` — браузерде ойнату). Дайын бейне: `media/globus-sayahat.mp4`.
- `materialdar.html` — ҚМЖ, презентация, жұмыс парақтары, наклейкалар, постерлер.

## Сабақ барысы
1. Сәлем + мақсат · 2. Үй тапсырмасы: «Ыстық орындық + глобус» · 3. Топқа бөлу (сақталған тізімнен) ·
4. Жаңа сабақ: «Глобус-саяхат» бейнесі · 5. Өзін-өзі басқару: 6 спикер + 7-ықпалды мұғалім ·
6. Тақтада: «Глобус-детектив» (3D глобус) · 7. «Экозертхана» постер және қорғау · 8. «Экожарыс» квизі (оқулық + Жетісай) ·
9. Рейтинг, номинациялар, кері байланыс, үй тапсырмасы.

## Бағалау
5 критерий, 12 ұпай → пайыз → 10 балл: 85–100% → 9–10, 65–84% → 7–8, 0–64% → 1–6.
Критерийлер мен дескрипторлар — тақтадағы 📋 панелінде, барлық дерек — `lesson-data.js`.

## Мұғалімге
- ⚙️ Баптау: оқушылар тізімі (бір рет), тең топтарға бөлу, QR, жаңа сабақ коды, құжаттар.
- Пернелер: ← → экран · Space таймер · M мұғалім сөзі · B бағалау · R рейтинг · T баптау.
- Офлайн тексеру: `index.html?demo=1`.
